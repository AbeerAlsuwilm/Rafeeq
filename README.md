# مشروع رفيق

## التشغيل
1. افتح مجلد المشروع في VS Code (File > Open Folder).
2. ثبّت إضافة **Live Server** (من تبويب Extensions).
3. كليك يمين على index.html ثم **Open with Live Server**.
(أو افتح index.html مباشرة بالمتصفح.)

## الملفات
- index.html : هيكل الصفحة
- style.css  : الألوان والتصميم (الألوان في أعلى الملف داخل :root)
- app.js     : الصفحات والتنقل والمنطق (كل صفحة داخل الكائن P)
